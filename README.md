# TinkerTab 🧪 — Selenium Automation for Kids

A playful, responsive one page landing site that introduces kids and beginners to Selenium automation and web testing, built as a single self contained `index.html` file with no build step and no dependencies beyond Google Fonts.

## About This Project

TinkerTab walks a young learner from "what even is a browser test" to "I could write one myself," using a friendly robot mascot, a five step learning trail, and simple, honest language throughout. It is designed to be dropped straight onto GitHub Pages with zero setup.

## Live Preview

Open `index.html` in any browser, or enable GitHub Pages on this repository (Settings → Pages → Deploy from branch → main → root) to get a live public link.

## What's Inside

- A sticky, playful header with quick navigation
- A hero section introducing the idea of teaching a browser to follow instructions
- A plain language explainer on what Selenium actually does
- A five stop "learning trail" that lays out the path from visual coding to real scripts
- A callout linking to the full, longer written guide
- Three action cards linking to a beginner course, a free demo class, and an advanced training path
- A footer with the same links, repeated for easy access

## Tech Notes

- Pure HTML and CSS, no framework, no build tools
- Fonts: Baloo 2 for headings, Nunito for body text, both loaded from Google Fonts
- Fully responsive down to small mobile screens
- Respects reduced motion preferences for the floating hero illustration
- All interactive elements are keyboard accessible with visible focus states from default browser styling

## How to Customize

Open `index.html` and edit the content directly inside the marked sections (hero, explainer, trail, cards, footer). Colors and fonts are defined as CSS custom properties near the top of the `<style>` block, so updating the palette only requires changing a handful of values in one place.
